## Installation

```bash
cargo install git-wipe
```

```bash
brew install noirbizarre/homebrew-tap/git-wipe
```

```bash
paru -S git-wipe-bin  # or your AUR helper of choice
```

Or download a binary for your platform from the
[latest release](https://github.com/noirbizarre/git-wipe/releases/latest).

## Usage

```bash
git-wipe --help
```
